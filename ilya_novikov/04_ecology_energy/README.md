# «БОРА-5»

- **Номинация:** Лучший инновационный проект в сфере охраны окружающей среды, энергосбережения и альтернативных источников энергии
- **Автор:** Новиков Илья · **Консультант:** Богус Азамат Эдуардович · **Член проектной группы:** Шершнев Игорь Андреевич
- **Суть.** Вертикально-осевая ВЭУ 5 кВт для зоны новороссийской боры: гибрид Дарье–Савониус, магнитный подвес ротора (нет смазки — нет обледенения), штормовой режим с полезным сбросом энергии на нагрев воды. Модель Б-01: старт 2,8 м/с; зимняя серия в бору до 24 м/с — 212 кВт·ч за 6 суток, 0 отказов. Головная Б-5: 9,6 МВт·ч/год, себестоимость 3,1 руб./кВт·ч против тарифа 7,2 руб., окупаемость 4,6 года, −5,1 т CO₂/год.

Файлы: `application.md` — заявка; `images/` — силовая цепь, экономика, чертёж; `code/` — MPPT и контроль подвеса; `docs/` — протоколы испытаний.
