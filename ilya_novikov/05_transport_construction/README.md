# ГРУНТ-ЭХО

**Номинация:** транспорт, строительство и ЖКХ. **Автор:** Новиков Илья. **Консультант:** Богус Азамат Эдуардович. **Член группы:** Шершнев Игорь Андреевич.

Пассивная сейсмическая интерферометрия: городской трафик — источник, 8 геотелефонов на обочине — приём. Скрытая полость над коллектором находится за 6 суток до просадки покрытия. Без бурения, без источника, без перекрытия улицы.

## Проблема

Серия провалов на ул. Московской, Краснодар: коллектор ∅1000 мм, провалы по 4 м, остановки трамваев (Юг Times, 93.ру, РБК, 2025). Износ сетей достигает 63 % (Утюг-инфо, 2026). Инклинометры требуют бурения в каждой точке.

## Уникальное решение

Взаимная корреляция шумовых записей двух точек восстанавливает функцию Грина между ними; скорость поперечных волн в верхних 6 м падает на 2–8 % над вымытым грунтом. 8 датчиков = 28 виртуальных трасс на 100 м. Коммерческих систем такого назначения в РФ нет.

## Параметры

| Параметр | Значение |
|---|---|
| Датчиков в комплекте | 8 (МП-8, 0,5–200 Гц) |
| Накопление | 7 ночей |
| Погрешность δv/v | 0,3 % |
| Пороги | −2,5 % жёлтый, −5 % красный |
| Пилот: полость 0,9 м³ | найдена за 6 суток до просадки |

## Экономика

380 тыс. руб./км обследования против 6–9 млн руб. аварийного ремонта провала. 15 км/год: прибыль медиана 3,1 млн руб./год, **окупаемость 7,4 месяца**.
