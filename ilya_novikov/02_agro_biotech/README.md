# «ЗЕРНО-РЕНТГЕН»

- **Номинация:** Лучший инновационный проект в сфере АПК, биотехнологий и пищевой промышленности
- **Автор:** Новиков Илья · **Консультант:** Богус Азамат Эдуардович · **Член проектной группы:** Шершнев Игорь Андреевич
- **Суть.** Потоковый рентгено-оптический сепаратор фузариозного зерна на приёмке элеватора: низкодозный рентген (плотность эндосперма) + ближний ИК (химическая сигнатура), эжекторная матрица 64 клапана. Совместная модель: точность 94,6 %, потеря чистого зерна 1,3 %. Выборка 3 200 зёрен, 6 кубанских сортов, 4 партии хозяйств засухи-2025: доля поражённых зёрен в товарной фракции снижена с 3,1–7,8 % до 0,4–0,9 %. Эффект элеватора 4,2 млн руб./сезон, окупаемость 1,3 сезона.

Файлы: `application.md` — заявка; `images/` — тракт, экономика, чертёж; `code/` — признаки и тайминг эжектора; `docs/` — протокол испытаний.
