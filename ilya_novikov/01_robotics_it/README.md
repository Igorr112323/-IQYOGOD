# «АГРОХОД-2»

- **Номинация:** Лучший инновационный проект в сфере робототехники, компьютерных технологий и телекоммуникаций
- **Автор:** Новиков Илья · **Консультант:** Богус Азамат Эдуардович · **Член проектной группы:** Шершнев Игорь Андреевич
- **Суть.** Автономная гусеничная платформа точечного опрыскивания интенсивного сада. Удержание в ряду ±27 мм (СКЗ) по бортовому лидару + сегментация крон; 8 посекционных форсунок. Полевое сравнение 2026 г.: расход рабочей жидкости 312 л/га против 452 л/га (−31 %) при равном покрытии листа. Наработка 86 ч, 412 авторазворотов. Серия 1,9 млн руб.; окупаемость услуги на 250 га — 1,4 сезона.

Файлы: `application.md` — заявка; `images/` — контур управления, экономика, чертёж; `code/` — удержание в ряду и управление форсунками; `docs/` — протокол испытаний.
