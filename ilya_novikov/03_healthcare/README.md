# «ТЕРМОСТОПА-32»

- **Номинация:** Лучший инновационный проект в сфере здравоохранения, биомедицины и фармации
- **Автор:** Новиков Илья · **Консультант:** Богус Азамат Эдуардович · **Член проектной группы:** Шершнев Игорь Андреевич
- **Суть:** автономная термоматрица подошвы: 32 датчика в стельке 2,1 мм, измерение 60 с, бортовой алгоритм попарной асимметрии зон (порог 2,0 °С), без смартфона и оператора, результат в МИС за 60 с. Испытания: 62 пациента с диабетом + 28 контрольных, 214 измерений, 9 подтверждённых случаев из 11 сигналов, погрешность ±0,15 °С. Устройство 68 тыс. руб., маржа 27 тыс. руб. Капзатраты проекта 2,9 млн руб., чистый результат 3,3 млн руб./год при 90 устройствах, окупаемость 10,5 месяца (< 2 лет). Монте-Карло 3 000 итераций.

Файлы: `application.md` — заявка; `images/` — контур, экономика, чертёж устройства; `code/` — алгоритм асимметрии и драйвер МИС; `docs/` — протокол испытаний.
