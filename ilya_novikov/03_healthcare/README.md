# «КИСТЬ-М»

- **Номинация:** Лучший инновационный проект в сфере здравоохранения, биомедицины, фармацевтики
- **Автор:** Новиков Илья · **Консультант:** Богус Азамат Эдуардович · **Член проектной группы:** Шершнев Игорь Андреевич
- **Суть.** Портативный экзоскелет кисти для постинсультной реабилитации: 780 г, 2 привода, момент 1,2 Н·м, аппаратный силовой предохранитель на тензодатчике (срабатывание 4,1 ± 0,2 Н·м, 240 испытаний, 0 отказов). Пилот с 6 добровольцами, 118 сеансов: сила хвата +18 %, объём разгибания +12°, 0 инцидентов. Монте-Карло 2 000 сценариев: окупаемость у медорганизации — медиана 2,1 месяца. Себестоимость 89 тыс. руб. против 2,5–6 млн руб. импортных комплексов; капзатраты проекта 1,8 млн руб., маржа серии 3,55 млн руб./год, окупаемость проекта 6 месяцев (< 2 лет).

Файлы: `application.md` — заявка; `images/` — контур управления, экономика, чертёж; `code/` — предохранитель и 3D-каркас; `docs/` — протокол испытаний.
