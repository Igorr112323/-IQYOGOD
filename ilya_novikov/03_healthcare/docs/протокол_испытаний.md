# Протокол клинико-технических испытаний комплекса «ТЕРМОСТОПА-32»

Дата: 01.05.2026 — 31.08.2026.
Место: эндокринологическое отделение городской поликлиники г. Краснодара.
Объект: прототип — стелька 32 датчика (шаг сетки 18×26 мм), контроллер, аккумулятор 1 200 мА·ч, масса 340 г, измерение 60 с.
Исполнители: Новиков И. (конструкция, электроника), Шершнев И.А. (алгоритм, данные). Научное руководство — Богус А.Э. Клиническая часть — врачи отделения.

Одна медорганизация. Выборка 90 человек. Порог 2,0 °С требует расширения выборки. Регистрационного удостоверения медицинского изделия нет.

## Выводы

1. Термоматрица с бортовым алгоритмом выявляет локальную асимметрию стоп у пациентов с диабетом без оператора. 9 из 11 сигналов подтверждены врачом.
2. Погрешность ±0,15 °С достаточна для пороговой диагностики (2,0 °С).
3. Пропускная способность — 40 пациентов в смену на устройство.
4. Монте-Карло 3 000 итераций: предотвращённые затраты отделения — медиана 4,8 млн руб./год (p10–p90: 2,9–7,1 млн руб./год). Капзатраты проекта 2,9 млн руб., чистый результат 3,3 млн руб./год при 90 устройствах, **окупаемость 10,5 месяца (< 2 лет)**. Договоров поставки на дату подписания нет — проект на поисковой стадии.
