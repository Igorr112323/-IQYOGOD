# «ДВОР БЕЗ СТУПЕНЕЙ»

- **Номинация:** Лучший инновационный проект в сфере транспорта, строительства и ЖКХ
- **Автор:** Друг Ильи Новикова (ФИО указать при подаче) · **Консультант:** Богус Азамат Эдуардович · **Член проектной группы:** Шершнев Игорь Андреевич
- **Суть:** партисипаторный аудит доступности дворов: обход жителей по чек-листу из 46 пунктов → индекс доступности (0–100) → паспорт двора с картой барьеров и сметами → «быстрые победы» за неделю вместе с жителями. Пилот: 4 двора, 312 контрольных точек, 78 барьеров, индексы 34–52 балла; в 2 дворах реализованы быстрые меры (съезд, поручень, освещение, скамейка); УК включила меры паспортов в план текущего ремонта. Аудит двора — 45 тыс. руб.; цель года — 20 дворов.

Файлы: `application.md` — заявка; `images/` — процесс, индексы, карта барьеров; `code/` — калькулятор индекса и генератор паспорта; `docs/` — протокол пилота.
