# «ДОСТУПНЫЙ КУРОРТ»

- **Номинация:** Лучший инновационный проект в сфере транспорта, строительства и ЖКХ
- **Автор:** Друг Ильи Новикова (ФИО указать при подаче) · **Консультант:** Богус Азамат Эдуардович · **Член проектной группы:** Шершнев Игорь Андреевич
- **Суть:** цифровая карта доступности курортов Кубани для маломобильных туристов: каждый объект проверяется полевым аудитом (42 параметра, уклономер и динамометр вместо анкеты) и получает паспорт доступности. Пилот лета 2026 г.: Анапа, Геленджик, Ейск — 240 объектов, 40 полных аудитов, 11 из 40 полностью доступны, 6 маршрутов «вокзал — пляж». Аудит с паспортом — 38 тыс. руб./объект, подписка муниципалитета — 45 тыс. руб./мес. Капзатраты 890 тыс. руб., чистый результат 3,4 млн руб./год, окупаемость 3,2 месяца (< 2 лет). Монте-Карло 2 000 сценариев: +6 % доступного турпотока за два сезона.

Файлы: `application.md` — заявка; `images/` — контур продукта, экономика, схема платформы; `code/` — конструктор паспортов и индекс территории; `docs/` — протокол пилотных аудитов.
