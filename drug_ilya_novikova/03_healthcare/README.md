# «ТЕНЬ КУБАНИ»

- **Номинация:** Лучший инновационный проект в сфере здравоохранения, биомедицины, фармацевтики
- **Автор:** Друг Ильи Новикова (ФИО указать при подаче) · **Консультант:** Богус Азамат Эдуардович · **Член проектной группы:** Шершнев Игорь Андреевич
- **Суть:** программа жарозащиты городов: тепловое картирование «ногами» (3 волны замеров, 280 точек, 42 волонтёра; разброс до 11 °С в одном квартале), теневые маршруты к школам и поликлиникам (доля тени 22 % → 58 %, жаровая нагрузка −18…−24 %), питьевые точки и жаровой протокол с обзвоном пожилых. Обкатка волны жары 24–29.07.2026: 137 обзвоненных, «прохладная комната» 89 посещений, питьевая точка 1 240 использований за июль. Стоимость программы городу 2,3 млн руб./год; экономия на скорой 1,1–1,7 млн руб./сезон.

Файлы: `application.md` — заявка; `images/` — модули, анализ замеров, схема маршрутов; `code/` — жаровой индекс и протокол; `docs/` — отчёт обкатки.
