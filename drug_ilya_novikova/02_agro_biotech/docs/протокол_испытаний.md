# Протокол пилотных испытаний системы «ЗАМОР-СТОП»

**Период:** 01.04.2026 — 25.09.2026.
**Место:** пруд на улице Восточно-Кругликовской, г. Краснодар (городской водоём с историей двух заморов в феврале–апреле 2026 г.); платный пруд рыболовного хозяйства Динского района.
**Оборудование:** два поста — ИК-камеры 4 Мп с подсветкой 850 нм, бортовые вычислители, солнечное питание, 4G; аэратор рыбохозяйства-партнёра.
**Ответственные:** автор (методика, взаимодействия), Шершнев И.А. (бортовая модель, электроника), привлечённый ихтиолог (верификация поведения).

## 1. Методика

1. Посты вели ночную съёмку акватории; модель детектировала всплытия и классифицировала эпизоды «плавания у поверхности» по динамике головы (заглатывание воздуха).
2. За первые 14 суток для каждого водоёма строилась базовая линия частоты эпизодов; тревога формировалась при превышении базовой линии в три раза за 40-минутное окно.
3. Эпизоды размечались ихтиологом по видео; ложные цели (утки, волны, блики фар) учитывались отдельно.
4. По тревоге на платном пруде включался аэратор; результат оценивался по объёму сохранённой рыбы.

## 2. Данные

| Показатель | Значение |

| Постов | 2 |
| Видеодатасет | 11 400 размеченных эпизодов |

| Заморных эпизодов за пилот | 2 |
| Ложных сигналов | 1 (ночной ливень с грозой) |

## 3. Результаты

| Метрика | Значение |
|---|---|
| Точность детекции эпизодов всплытия | **0,93** |
| Эпизод 1 (платный пруд, июнь) | тревога за **7 часов** до начала массовой гибели |
| Эпизод 2 (платный пруд, август) | тревога за **5 часов** до начала массовой гибели |
| Сохранено аэрацией по тревоге | 2,1 т рыбы (оценка рыбохозяйства) |
| Время формирования тревоги | ≤ 60 секунд |

На городском пруду за пилот заморных эпизодов не случилось; наблюдение продолжается по договорённости с администрацией парка.

## 4. Монте-Карло (экономика)

3 000 сценариев (`images/zamor_economics.py`): при 24 постах выручка медиана 9,1 млн руб./год (посты, подписки, сезонные контракты), прибыль медиана 2,6 млн руб./год, окупаемость стартовых затрат 3,7 млн руб. — медиана 17,0 месяца, 95-й процентиль 24,6 месяца, доля сценариев с окупаемостью до 24 месяцев — 0,94.

## 5. Ограничения

- пилот на двух пресноводных водоёмах; лиманы с солоноватой водой и ветровым нагоном требуют калибровки базовых линий;
- зимний подо льдом замор камерой не наблюдается — для него предусмотрена сезонная конфигурация;
- договоры с муниципалитетами не заключены; проект на поисковой стадии.

## 6. Заключение

Посты устойчиво детектируют предзаморное поведение рыбы и поднимают тревогу за 5–7 часов до массовой гибели. Система рекомендуется к серии из 24 постов и развёртыванию на шести водоёмах края в 2027 году.
