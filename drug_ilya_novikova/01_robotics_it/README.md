# «ЭКОСИГНАЛ КУБАНИ»

- **Номинация:** Лучший инновационный проект в сфере робототехники, компьютерных технологий и телекоммуникаций
- **Автор:** Друг Ильи Новикова (ФИО указать при подаче) · **Консультант:** Богус Азамат Эдуардович · **Член проектной группы:** Шершнев Игорь Андреевич
- **Суть:** гражданская платформа экомониторинга: сигнал жителя с фото → автоматическая маршрутизация по полномочиям → работа → подтверждение результатом жителем. Плюс сеть школьных датчиков воздуха по 1 900 руб. и публичный экологический рейтинг районов. Пилот (8 недель, 3 школы, 2 волонтёрские организации): 214 сигналов, 63 % решены, точность модерации 91 %, средний срок реакции 19 → 7 дней, 74 школьника в проекте. Подписка для района 85 тыс. руб./мес; окупаемость платформы < 2 месяцев.

Файлы: `application.md` — заявка; `images/` — жизненный цикл, статистика пилота, схема; `code/` — маршрутизатор и прошивка датчика; `docs/` — отчёт пилота.
