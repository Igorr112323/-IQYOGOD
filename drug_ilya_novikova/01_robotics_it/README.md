# «ЭКОСИГНАЛ КУБАНИ»

- **Номинация:** Лучший инновационный проект в сфере робототехники, компьютерных технологий и телекоммуникаций
- **Автор:** Друг Ильи Новикова (ФИО указать при подаче) · **Консультант:** Богус Азамат Эдуардович · **Член проектной группы:** Шершнев Игорь Андреевич
- **Суть:** гражданская платформа экомониторинга: сигнал жителя с фото → автоматическая маршрутизация по полномочиям → работа → подтверждение результатом жителем. Плюс сеть школьных датчиков воздуха по 1 900 руб. и публичный экологический рейтинг районов. Пилот (8 недель, 3 школы, 2 волонтёрские организации): 214 сигналов, 63 % решены, точность модерации 91 %, средний срок реакции 19 → 7 дней, 74 школьника в проекте. Монте-Карло 2 000 сценариев нагрузки. Капзатраты масштабирования 1,6 млн руб.; подписка для района 85 тыс. руб./мес, чистый результат 8,5 млн руб./год при 15 районах, окупаемость 2,3 месяца (< 2 лет).

Файлы: `application.md` — заявка; `images/` — жизненный цикл, статистика пилота, схема; `code/` — маршрутизатор и прошивка датчика; `docs/` — отчёт пилота.
