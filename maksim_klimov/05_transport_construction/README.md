# «ВТОРАЯ ЖИЗНЬ ПЛАСТИКА»

- **Номинация:** Лучший инновационный проект в сфере транспорта, строительства и ЖКХ
- **Автор:** Климов Максим · **Консультант:** Богус Азамат Эдуардович · **Член проектной группы:** Шершнев Игорь Андреевич
- **Суть:** мобильный комплекс переработки смешанных пластиков без сортировки: микс 60 % + песок 40 % → пескополимерный композит 28 МПа (бетон М200 — 20 МПа), морозостойкость F75. Скамейки, урны, плитка, остановки. Три потока дохода: приём отходов (дешевле полигона), продажа мебели, брендированные контракты РОП. 480 т/год и 600 единиц мебели: выручка 14,2 млн руб./год, маржа 5,9 млн руб., окупаемость 2,4 года. На первой акции переработано 800 кг.

Файлы: `application.md` — заявка; `images/` — цикл, экономика, схема комплекса; `code/` — контроллер пресса и калькулятор рецептур; `docs/` — протокол испытаний.
