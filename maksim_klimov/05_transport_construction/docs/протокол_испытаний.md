# Протокол пилотного сезона сети «ЛИВЕНЬ-ПРО»

- **Дата:** 01.05.2026 – 31.08.2026
- **Место:** Центральный и Западный округа г. Краснодара (Гаврилова, Одесская, Северная, Мусоргского)
- **Объект:** 40 датчиков двух типов: акустический сенсор засора решётки «ЛИВЕНЬ-Р», уровнемер коллектора «ЛИВЕНЬ-К»; батарея, LoRaWAN, монтаж без рытья
- **Исполнители:** Климов М. (продукт, взаимодействие со службами), Шершнев И.А. (сенсоры, гидравлическое ядро); экспертиза — Богус А.Э.

## Калибровка модели

Гидравлическая модель двух кварталов откалибрована по 11 историческим подтоплениям 2024–2025 гг.: совпадение зон — 8 из 11, на трёх событиях прогноз сместился на соседние участки. Пороги нарядов согласованы со службой эксплуатации.

## Выводы

1. Предиктивная диспетчеризация работает: на отработанных заранее участках подтоплений не зафиксировано.
2. Акустическая оценка засора решёток пригодна к эксплуатации: датчики различают «чисто», «частично забито», «забито» с согласованностью 88 % при выборочных визуальных проверках.
3. Экономика (Монте-Карло, 3 000 сценариев): ущерб одного подтопления районного масштаба медиана 9,4 млн руб.; платформа окупается городом за 3 предотвращённых события. Капзатраты проекта 6,4 млн руб., чистый результат 7,8 млн руб./год при трёх районах, **окупаемость 9,8 месяца (< 2 лет)**.
4. Контрактов на поставку на дату подписания нет — проект на поисковой стадии.
