# «КУБАНЬ-ХРУСТ»

- **Номинация:** Лучший инновационный проект в сфере АПК, биотехнологий и пищевой промышленности
- **Автор:** Климов Максим · **Консультант:** Богус Азамат Эдуардович · **Член проектной группы:** Шершнев Игорь Андреевич
- **Суть:** бренд фруктовых снеков из некондиции кубанских садов (15–20 % урожая вне товарного вида). Гибридная ИК-конвективная сушка: 1,9 кВт·ч/кг против 2,7 (−30 % энергии). Действующий цех 120 кг/сутки, отгружено 612 кг, выручка 603 тыс. руб. за 3 месяца, повторные заказы 2 отелей Сириуса. Стационар: 28 млн руб. выручки, маржа 28 %, +7,5 млн руб. садоводческим хозяйствам за некондицию.

Файлы: `application.md` — заявка; `images/` — цепочка, экономика, схема линии; `code/` — контроллер сушки и QR-паспорта; `docs/` — протокол испытаний.
