# ЛОЗА-ФУРАЖ

**Номинация:** АПК, биотехнологии, пищевая промышленность. **Автор:** Климов Максим. **Консультант:** Богус Азамат Эдуардович. **Член команды:** Шершнев Игорь Андреевич.

Первая в винных регионах России линия заквашивания виноградной выжимки в кормовую добавку для молочного скота — без сушки, прямо у винодельни. Рекордные 313 тыс. т урожая превращаются не в проблему, а в корм!

## Проблема

Урожай-2025: 313 тыс. т винограда (+30 %), выпуск вина 25 млн декалитров. Выжимки — 20–25 % сырья, то есть 47–78 тыс. т/год по краю: закисают на полях, пахнут, теряют ценность за недели (Утюг-инфо, Кубанские новости, РИА, 2026). Сушить энергетически разорительно.

## Уникальное решение

Молочнокислое заквашивание в герметичных контейнерах: рН 4,1 к 21-му дню, хранение 12+ месяцев, полифенолы сохранены. Коммерческих линий такого профиля в РФ не выявлено.

## Доказанный эффект (протокол)

120 коров, 60 дней, Павловский район: надой **+4,2 %**, соматические клетки **−9 %**, затраты на корма **−11 %**.

## Экономика

Себестоимость 1 750 руб./т, цена 2 900 руб./т, маржа 39,7 %. Линия 5 000 т/сезон: чистая прибыль медиана 5,8 млн руб./год, капзатраты 4,1 млн руб., **окупаемость 8,5 месяца**.
