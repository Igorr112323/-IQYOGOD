# «СОЛНЦЕПАРК»

- **Номинация:** Лучший инновационный проект в сфере охраны окружающей среды, энергосбережения и альтернативных источников энергии
- **Автор:** Климов Максим · **Консультант:** Богус Азамат Эдуардович · **Член проектной группы:** Шершнев Игорь Андреевич
- **Суть:** модульные солнечные навесы над парковками отелей: 22 кВт панелей + 40 кВт·ч накопитель + зарядки электромобилей. Модель energy-as-a-service: отель платит только за киловатт-часы (дешевле пикового тарифа). Пилот за сезон: 5,4 МВт·ч, самопотребление 92 %, срез пика 38 кВт, кондиционирование затенённого корпуса −6,2 %, 312 сессий зарядки. Сеть 15 модулей: маржа ≈ 13,5 млн руб./год, −200 т CO₂/год.

Файлы: `application.md` — заявка; `images/` — энергобаланс, экономика, чертёж навеса; `code/` — диспетчер и прогноз генерации; `docs/` — протокол пилота.
