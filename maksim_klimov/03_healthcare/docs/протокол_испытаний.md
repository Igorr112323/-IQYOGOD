# Протокол пилотного исследования прибора «КЕРАТИН-ГЛИК»

**Период:** 01.04.2026 — 28.09.2026.
**Место:** эндокринологический кабинет-партнёр, г. Краснодар; референсные анализы — лаборатория-партнёр.
**Оборудование:** настольный рамановский спектрометр (лазер 785 нм, 300 мВт), окно фиксации пальца, версия прошивки 0.8.6.
**Ответственные:** автор (клинические партнёрства), Шершнев И.А. (оптика, модель), привлечённый врач-эндокринолог.

## 1. Дизайн

1. Добровольцы 25–74 лет, информированное согласие; статус СД 2 типа подтверждён документально.
2. Измерение: 3 точки ногтевой пластины указательного пальца, суммарно 45 секунд.
3. Референс: лабораторный HbA1c (HPLC) в день измерения, ослеплённый к результату прибора.

## 2. Данные

| Показатель | Значение |
|---|---|
| Добровольцев | 84 |
| Измерений | 226 |
| Пациентов с СД 2 типа | 30 |
| Диапазон лабораторного HbA1c | 4,9–10,8 % |
| Отложенная выборка | 30 %, стратификация по HbA1c |

## 3. Результаты

| Метрика | Значение |
|---|---|
| Корреляция с лабораторным HbA1c | **0,87** |
| Средняя абсолютная ошибка | 0,42 % |
| Чувствительность к HbA1c ≥ 7,0 % | 0,90 |
| Специфичность | 0,84 |
| Время измерения | 45 с |
| Доля нечитаемых спектров | 2,2 % |

## 4. Монте-Карло (экономика)

3 000 сценариев (`images/keratin_economics.py`): при 20 приборах в крае прибыль медиана 4,6 млн руб./год (квартили 3,8–5,5), окупаемость стартовых затрат 3,2 млн руб. — медиана 12,8 месяца, 95-й процентиль 19,7 месяца, доля сценариев с окупаемостью до 24 месяцев — 0,94.

## 5. Ограничения

- выборка пилотная (84 человека); расширение до 300 пациентов в трёх центрах — следующий этап;
- прибор является скрининговым инструментом и не заменяет лабораторный анализ;
- регистрационное удостоверение медицинского изделия не оформлялось;
- на 2,2 % измерений спектр оказывался нечитаемым (лак, повреждения ногтя) — измерение повторяется.

## 6. Заключение

Рамановская спектроскопия ногтевой пластины продемонстрировала устойчивую связь с лабораторным HbA1c и пригодна для безинвазивного скрининга накопленного гликемического контроля. Прибор рекомендуется к расширенной клинической валидации и подготовке досье медицинского изделия.
