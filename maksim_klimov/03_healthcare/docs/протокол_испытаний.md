# Протокол пилотной эксплуатации станции «ПУЛЬС-ПОЙНТ»

- **Дата:** 04.04.2026 – 16.05.2026 (6 недель)
- **Место:** холл учебного корпуса ФГБОУ ВО «Кубанский ГАУ»
- **Исполнители:** Климов М. (продукт, аналитика), Шершнев И.А. (плата сбора, софт); научная экспертиза — Богус А.Э.; врачебный контроль маршрутов — врач-партнёр.

## Объём выборки

1 240 сеансов; возраст пользователей: до 25 лет — 34 %, 25–44 — 28 %, 45+ — 38 %.

## Ключевые показатели

| Показатель | Значение |
|---|---|
| Среднее время сеанса | 3 мин 10 с |
| Повышенное АД (≥ 140/90) | 7,8 % сеансов |
| Из них не измеряли АД > 1 года | 61 % |
| Красные маршруты | 1,9 % |
| Ложные красные (врачебный контроль) | 0,4 % |
| Чувствительность триажа к случаям очного приёма | 0,94 |
| Специфичность | 0,91 |
| Отказы оборудования | 2 (замена манжеты, калибровка термометра) |
| Доступность станции | 98,6 % |

## Коммерческие сигналы

- 3 письма о намерениях от санаториев Геленджика (7 станций суммарно).
- Готовность платить за чек-ап вне подписки: 54 % опрошенных пользователей (190 руб. — приемлемо для 71 %).
- Запрос от пилотной площадки: продление на осень «для сотрудников».

## Выводы

1. Станция работоспособна без оператора; узлы дезинфекции и замены манжет — в серийном ТЗ.
2. Триажирующие правила подтверждены контролем врача; доля красных маршрутов ≤ 2 %.
3. Допуск к серийному корпусу и пилотным контрактам этапа 4.
