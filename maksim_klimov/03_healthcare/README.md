# «ОКО-СКРИН»

- **Номинация:** Лучший инновационный проект в сфере здравоохранения, биомедицины и фармации
- **Автор:** Климов Максим · **Консультант:** Богус Азамат Эдуардович · **Член проектной группы:** Шершнев Игорь Андреевич
- **Суть:** портативный офтальмоскрининг диабетической ретинопатии прямо в кабинете эндокринолога районной поликлиники: безмидриатический фундус-сканер 2,8 кг + бортовой офлайн-ИИ (заключение за 40 секунд без облака) + телемедицинская маршрутизация. Валидация: 1 140 пациентов с диабетом, чувствительность 0,92 при специфичности 0,87, 96 % годных снимков; 9 пациентов с угрожающими признаками направлены в течение 3 дней. Станция 1,19 млн руб. или аренда 89 тыс./мес. Капзатраты проекта 4,8 млн руб., чистый результат 3,6 млн руб./год при 10 станциях — окупаемость 16 месяцев (< 2 лет). Монте-Карло 3 000 сценариев.

Файлы: `application.md` — заявка; `images/` — контур скрининга, экономика, чертёж станции; `code/` — бортовой инференс и маршрутизация; `docs/` — протокол клинической валидации.
