# «ПУЛЬС-ПОЙНТ»

- **Номинация:** Лучший инновационный проект в сфере здравоохранения, биомедицины, фармацевтики
- **Автор:** Климов Максим · **Консультант:** Богус Азамат Эдуардович · **Член проектной группы:** Шершнев Игорь Андреевич
- **Суть:** сеть безоператорных экспресс-чек-ап станций (тонометр, пульсоксиметр, термометр, весы) с ИИ-триажем для курортов. Пилот: 1 240 измерений, повышенное давление у 7,8 % (61 % из них не измеряли его больше года), чувствительность триажа 0,94. Модель: подписка отелей 24,9 тыс. руб./мес + платные чек-апы 190 руб. Сеть из 50 станций: выручка 36,2 млн руб./год, окупаемость за один высокий сезон; разгрузка курортных поликлиник ≈ −12 % нецелевых визитов.

Файлы: `application.md` — заявка; `images/` — маршрут, экономика, чертёж; `code/` — триаж и драйверы приборов; `docs/` — протокол пилота.
