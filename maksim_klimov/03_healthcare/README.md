# КЕРАТИН-ГЛИК

**Номинация:** здравоохранение, биомедицина и фармация. **Автор:** Климов Максим. **Консультант:** Богус Азамат Эдуардович. **Член команды:** Шершнев Игорь Андреевич.

Первый отечественный безинвазивный скрининг накопленного гликемического контроля: 45 секунд прикладывания ногтя — и врач видит эквивалент HbA1c за 2–3 месяца без укола!

## Проблема

В крае 200 тыс. пациентов с диабетом (Новая Кубань, Кубань 24, 2026), диабет назван неинфекционной пандемией (Юга.ру, 2026). Контроль по крови 2–4 раза в год, при дефиците 5,4 тыс. медработников — этого мало. Между визитами пациент слеп к своей гликемии.

## Уникальное решение

Кератин ногтя гликируется глюкозой, как гемоглобин, и отражает 2–3 месяца гликемии. Рамановская спектроскопия (785 нм) читает полосы 1450/1650 см⁻¹ без забора биоматериала. Коммерческих приборов такой функции в РФ нет.

## Доказано на прототипе

84 добровольца, 226 измерений, из них 30 с СД 2 типа: корреляция с лабораторным HbA1c **r = 0,87**, MAE 0,42 %, чувствительность 0,90, специфичность 0,84.

## Экономика

Прибор 340 тыс. руб. + подписка 24 тыс./год; себестоимость ≤ 210 тыс. руб. При 20 приборах в крае: прибыль медиана 4,6 млн руб./год, **окупаемость 12,8 месяца**.
