# Протокол лабораторных испытаний модуля «ИСКРА-СТОП»

**Период:** 01.03.2026 — 20.09.2026.
**Место:** лаборатория Кубанского ГАУ, конвейерный стенд 0,8 м/с.
**Оборудование:** прототип вольтметрического блока (3 шт.), магнитоиндукционный контур, манипулятор 4 DOF с вакуумно-магнитным захватом.
**Ответственные:** автор (продукт, методика), Шершнев И.А. (электроника, управление).

## 1. Методика

1. Смешанные ТКО (плёнка, картон, стекло, текстиль, пищевые остатки) формировались в пробы по 10–15 кг; источники тока закладывались на случайных глубинах, в том числе внутри закрытых пакетов.
2. Протокол слепого закладывания: оператор конвейера не знал положение закладки до подведения итогов серии.
3. Метрики: детектирование (доля найденных), извлечение (доля извлечённых до дробилки), ложные захваты.

## 2. Данные

| Показатель | Значение |
|---|---|
| Проб ТКО | 1 240 |
| Закладок источников тока | 84 (АА/ААА 38, «крона» 9, дисковые литиевые 21, аккумуляторы телефонов 16) |
| Скорость ленты | 0,8 м/с |

## 3. Результаты

| Тип источника | Детектирование | Извлечение |
|---|---|---|
| Дисковые литиевые (ЭДС ~3 В) | 1,00 | 0,95 |
| Щелочные АА/ААА новые | 0,97 | 0,92 |
| Аккумуляторы телефонов | 0,94 | 0,88 |
| Солевые разряженные | 0,71 | 0,65 |
| **Итого** | **0,93** | **0,88** |

Ложные захваты — 2,1 % (фольгированные пакеты с остаточным потенциалом статики; устраняется калибровкой нулевой точки каждые 30 минут).

## 4. Монте-Карло (экономика)

3 000 сценариев для оператора МСК (`images/iskra_economics.py`): медиана эффекта 5,1 млн руб./год (предотвращённые простои + передача утилизатору), окупаемость модуля 5,3 млн руб. — медиана 14,2 месяца, 95-й процентиль 21,6 месяца, доля сценариев с окупаемостью до 24 месяцев — 0,93.

## 5. Ограничения

- стенд уже реального потока МСК по производительности (лабораторный конвейер против промышленных 40 т/ч) — промышленный образец следующий этап;
- разряженные солевые элементы детектируются хуже всех (0,71) — частично компенсируются магнитоиндукционным контуром;
- договоры поставки не заключены, проект на поисковой стадии.

## 6. Заключение

Вольтметрическое детектирование остаточного заряда подтверждено экспериментально: источник тока в смешанном потоке ТКО различим и извлекаем до дробилки. Модуль рекомендуется к изготовлению промышленного образца для пилота на МСК-партнёре.
