# Протокол ресурсных испытаний прототипа «ЮЖНЫЙ РОБОКУРЬЕР» К-1

- **Дата:** 15.03.2026 – 30.06.2026
- **Место:** тестовый полигон проекта, г. Краснодар (покрытия: брусчатка, гравий, асфальт; уклоны до 8°)
- **Исполнители:** Климов М. (продукт, сценарии), Шершнев И.А. (навигация, телеметрия); научная экспертиза — Богус А.Э.

## Программа испытаний

1. Ресурсный пробег до отказа или 320 км.
2. Обход препятствий: статичные (столбы, скамейки), динамичные (люди, самокаты), смешанные.
3. Работа при +35…+38 °С (контроль температуры батарейного отсека).
4. Потеря и восстановление GNSS (тень зданий), работа по лидару.

## Результаты

| Показатель | Значение |
|---|---|
| Пробег суммарный | 320 км |
| Встреч с препятствиями | 1 240 |
| Успешных разъездов | 99,2 % (1 230) |
| Контактов с людьми и объектами | 0 |
| Отказов навигации | 3 (все — потеря GNSS; восстановление по лидару ≤ 4 с) |
| Температура батарейного отсека при +38 °С снаружи | до +47 °С (без термостатизации) → в К-2 активное охлаждение |
| Фактический запас хода | 55 км (батарея 48 В · 30 А·ч, груз 40 кг) |

## Выводы

1. Платформа жизнеспособна на курортных покрытиях; главный дорабатываемый узел — термостатирование батареи (стенд: +47 °С без термостатизации → ≤ +29 °С с активной в К-2).
2. Навигационный стек обеспечивает требуемый уровень безопасности для пилота с оператором.
3. Коммерческих доставок на дату подписания не выполнялось — проект на поисковой стадии; допуск к сборке К-2 и пилотному развёртыванию в Сириусе (сезон-2027).
4. Экономика (расчётная, Монте-Карло 3 000 сценариев): маржа на ровер 282 тыс. руб./год, окупаемость серийного ровера 1,7 года, флота 9,3 млн руб. — менее 1 сезона при валовой прибыли 13,6 млн руб./сезон.
