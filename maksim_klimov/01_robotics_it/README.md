# «ЮЖНЫЙ РОБОКУРЬЕР»

- **Номинация:** Лучший инновационный проект в сфере робототехники, компьютерных технологий и телекоммуникаций
- **Автор:** Климов Максим · **Консультант:** Богус Азамат Эдуардович · **Член проектной группы:** Шершнев Игорь Андреевич
- **Суть:** флот автономных роверов доставки для курортов Сириуса и Сочи: груз 60 кг, запас хода 55 км, навигация в плотном пешеходном потоке (99,2 % успешных разъездов за 320 км пробега, 0 контактов, Монте-Карло 3 000 сценариев). Модель RaaS: 190 руб./доставка + подписка отелей. Капзатраты флота-пилота 9,3 млн руб.; валовая прибыль флота 10 машин ≈ 13,6 млн руб./сезон — окупаемость < 1 сезона, по роверу 1,7 года. Рынок «последних 300 метров» Сириуса — 300+ млн руб./сезон; собрано 1 213 предзаказов.

Файлы: `application.md` — заявка; `images/` — схема флота, юнит-экономика, чертёж; `code/` — диспетчер и планировщик; `docs/` — протокол испытаний.
