# Протокол пилотных испытаний комплекса «РИТМ-КАДРЫ»

**Период:** 09.01.2026 — 25.09.2026.
**Место:** поликлиника и травматологическое отделение стационара, г. Краснодар.
**Оборудование:** два киоска комплекса (направленный микрофон, вычислительный модуль, интеграция с табелем смен).
**Ответственные:** автор (методика, взаимодействие), Шершнев И.А. (акустический тракт, классификатор), привлечённый психолог службы (разметка контрольных эпизодов).

## 1. Методика

1. Участники проходили 40-секундный голосовой тест перед сменой на киоске в ординаторской; записи обрабатывались в контуре организации и не передавались наружу.
2. Эпизоды выраженного утомления фиксировались психологом службы по контрольным опросам и служебным наблюдениям; эти эпизоды составили эталонную разметку.
3. По «красным» индексам старшая медсестра корректировала нагрузку по регламенту; через две недели проводился контрольный опрос.

## 2. Данные

| Показатель | Значение |
|---|---|
| Участников | 164 |
| Тестов выполнено | 3 870 |
| Эпизодов утомления в разметке | 57 |
| Время теста | 40 секунд |

## 3. Результаты

| Метрика | Значение |
|---|---|
| Чувствительность к эпизодам утомления | **0,84** |
| Специфичность | **0,81** |
| «Красных» индексов с корректировкой нагрузки | 11 |
| Подтвердивших улучшение после корректировки | 8 из 11 |

По трём «красным» индексам участники отказались от корректировки нагрузки по личному решению; их данные учтены отдельно.

## 4. Монте-Карло (экономика)

3 000 сценариев (`images/ritm_economics.py`): при 34 лицензиях в первый год выручка медиана 9,8 млн руб./год, прибыль медиана 2,9 млн руб./год, окупаемость стартовых затрат 4,2 млн руб. — медиана 15,1 месяца, 95-й процентиль 22,6 месяца, доля сценариев с окупаемостью до 24 месяцев — 0,88.

## 5. Ограничения

- пилот в двух организациях одного города; классификатор требует дообучения на новых данных;
- комплекс не ставит диагнозов и не заменяет врача; это инструмент кадровой профилактики;
- госконтракты не заключены; проект на поисковой стадии.

## 6. Заключение

Голосовой скрининг устойчиво фиксирует накопленное утомление медработников и обеспечивает управленческую реакцию до кадровых последствий. Комплекс рекомендуется к серии и заключению контрактов с пятью медицинскими организациями в 2027 году.
