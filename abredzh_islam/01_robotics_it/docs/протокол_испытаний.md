# Протокол пилотной эксплуатации «МУНИЦИПАЛЬНЫЙ ВИДЕОКОНТРОЛЬ»

- **Период:** 01.04.2026 – 01.06.2026 (62 дня)
- **Объект:** пилотное муниципальное образование Краснодарского края (наименование уточняется при подаче)
- **Исполнители:** Абредж И. (управление, регламенты), Шершнев И.А. (разработка, видеоаналитика); научное руководство — Богус А.Э.

## Развёртывание

| Параметр | Значение |
|---|---|
| Подключено камер | 18 существующих, без закупок |
| Контрактов в контроле | 4 маршрута перевозок + 2 дорожных объекта |
| Затраты на пилот | 900 тыс. руб. (собственные средства) |

## Результаты контроля

| Показатель | Значение |
|---|---|
| Нарушений расписания | 214 |
| Невыполненных («призрачных») рейсов | 9 |
| Неотработанных оплаченных часов техники | 26 ч |
| Начислено неустоек по методике контрактов | **840 тыс. руб.** |

| Точность распознавания: норма / дождь-туман | 98 % / 87 % |

Каждое нарушение подтверждено двукратно (две камеры либо камера + ГЛОНАСС); спорных записей при выборочной проверке заказчиком — 0 из 50.

## Ограничения

62 дня, один муниципалитет; сложный метеофонд снижает точность; полный юридический цикл претензий завершится по итогам пилота.

## Выводы

Платформа пригодна к промышленной эксплуатации: эффект бюджета за пилот — 1,14 млн руб., окупаемость лицензии менее года. Допуск к этапу 4: регламент и контракт со вторым муниципальным образованием.
