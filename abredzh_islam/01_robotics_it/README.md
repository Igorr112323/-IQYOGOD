# ТРОС-ВЕКС

**Номинация:** робототехника, ИИ, информационные технологии. **Автор:** Абредж Ислам. **Консультант:** Богус Азамат Эдуардович. **Член группы:** Шершнев Игорь Андреевич.

Каждый новый лифт краевой программы капремонта получает магнитное кольцо на канатах — и с первого дня ведёт ресурсный журнал: телеметрия износа каждые сутки, без вызова дефектоскописта.

## Проблема

Краснодарский край меняет 197 лифтов в 2026 году, почти 9 млрд руб. по программе (Живая Кубань); с 2014 года заменено 2,8 тыс. лифтов (Коммерсантъ). Дальше за канатом следят визуальными осмотрами по регламенту ТО — износ между проверками невидим, решение о замене принимается по факту предельного состояния.

## Уникальное решение

Кольцо с 8 магнитами и 8 датчиками Холла на каждом канате: ночной прогон на 0,1 м/с, измерение потери сечения (LF) и обрывов проволок (LMA), тренды по каждому ручью. Ручные дефектоскопы применяются эпизодически; встроенной постоянной телеметрии ресурса канатов серийные лифтовые системы не предлагают.

## Задел

2 лифта Краснодара, 11 месяцев телеметрии (полнота 99,4 % суток): снижение сечения **−1,8 %** против контрольного ручного замера **−2,1 %** (согласованность **0,86**); 3 обрыва проволок детектированы и подтверждены визуально.

## Экономика

Комплект 180 тыс. руб./лифт + телеметрия 48 тыс./год. 60 лифтов в первый год: выручка медиана 13,7 млн руб./год, прибыль 3,3 млн руб./год, **окупаемость 14,3 месяца**.
