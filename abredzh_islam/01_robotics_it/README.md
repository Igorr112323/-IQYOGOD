# «МУНИЦИПАЛЬНЫЙ ВИДЕОКОНТРОЛЬ»

- **Номинация:** Лучший инновационный проект в сфере робототехники, компьютерных технологий и телекоммуникаций
- **Автор:** Абредж Ислам · **Консультант:** Богус Азамат Эдуардович · **Член проектной группы:** Шершнев Игорь Андреевич
- **Суть:** платформа автоматизированного контроля исполнения муниципальных контрактов на перевозки и дорожные работы: существующие городские камеры + реестр расписаний и графиков → верифицированный журнал нарушений → неустойки по 44-ФЗ. Пилот 62 дня на 18 камерах: 214 нарушений расписания, 9 «призрачных» рейсов, неустойки 840 тыс. руб., дисциплина интервалов 74 % → 89 %. Лицензия 1,2 млн руб./год; эффект бюджета 0,9–1,5 % объёма контрактов, окупаемость < 1 года.

Файлы: `application.md` — заявка; `images/` — контур, экономика, архитектура; `code/` — события и претензионный журнал; `docs/` — протокол пилота.
