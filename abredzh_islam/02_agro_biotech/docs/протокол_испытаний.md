# Протокол пилотной кампании «КУБАНЬ-УРОЖАЙ»

- **Период:** уборка 07.2025 (приёмка) – 03.2026 (реализация)
- **Место:** арендованные складские мощности, ст-ца Павловская
- **Исполнители:** Абредж И. (управление, экономика), Шершнев И.А. (запись, учёт); научное руководство — Богус А.Э.

## Показатели пилота

| Параметр | Значение |
|---|---|
| Хозяйств | 14 (от 45 до 210 т) |
| Принято пшеницы | **1 200 т** |
| Качественных лотов | 3 (протеин 11,8–14,1 %) |
| Цена реализации к цене «с колёс» | **+1 850 руб./т** |
| Дополнительная выручка хозяйств | **2,2 млн руб.** |
| Потери массы | **1,6 %** (районный фон 4,2 %) |
| Ожидание приёмки | **40 мин** (было 8 ч) |
| Подработка | партнёрский ток (собственной сушки в пилоте не было) |

Реализация лотов подтверждена выписками двух покупателей; цены сверены с котировочным монитором пилота.

## Финансирование

Грант на материально-техническую базу кооператива — 12 млн руб. (лаборатория, весовое). Собственные средства — 3,4 млн руб. Заявка на льготный кредит Минсельхоза в проработке.

## Ограничения

Арендованные мощности без собственной сушки; один сезон; статистика пилота не переносится на полный масштаб без оговорок.

## Выводы

Кооперационная модель доказана деньгами пилота. Хозяйства подписали протокол о намерениях; площадка полного цикла предварительно согласована. Допуск к этапу 2 — регистрация кооператива и проектирование.
