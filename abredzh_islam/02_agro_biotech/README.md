# «ЗЕРНОВОЙ ПАСПОРТ»

- **Номинация:** Лучший инновационный проект в сфере агропромышленного комплекса, биотехнологий и пищевой промышленности
- **Автор:** Абредж Ислам · **Консультант:** Богус Азамат Эдуардович · **Член проектной группы:** Шершнев Игорь Андреевич
- **Суть:** мобильный ИК-пост у весовой: за 90 секунд — паспорт партии (влажность, натура, протеин, клейковина, примесь) с маршрутизацией режимов (доработка / хранение по классу / отгрузка) и взаиморасчётами по данным паспорта. Уборка 2026 на току в Динском районе: 1 340 паспортов, расхождение с лабораторией 0,4 п.п. по влажности, 96 партий на доработку до смешения, 214 т предотвращённых потерь, 4,6 млн руб. экономии, простой машин 42 → 19 минут. Пост 890 тыс. руб., сопровождение 46 тыс. руб./мес. Капзатраты 4,66 млн руб., чистый результат 6,7 млн руб./год при двух сезонах, окупаемость 8,3 месяца (< 2 лет). Монте-Карло 3 000 сценариев: экономия хозяйства медиана 11,8 млн руб. на ток за сезон.

Файлы: `application.md` — заявка; `images/` — контур, экономика, пост; `code/` — паспорт партии и взаиморасчёты; `docs/` — протокол испытаний.
