# Протокол пилотного испытания платформы «КАПРЕМОНТ-КОНТРОЛЬ»

Дата: 01.03.2026 — 30.09.2026.
Место: восемь многоквартирных домов Краснодара и Динского района (кровля, фасад, инженерные системы).
Объект: приёмочный контур — измерительный комплект с планшетом (лазерный дальномер, толщиномер, влагомер, тепловизор), фотоверификация по чек-листам, электронный журнал контракта.
Исполнители: Абредж И. (договорная работа, муниципалитеты), Шершнев И.А. (комплект и платформа). Научное руководство — Богус А.Э.

| Показатель | Значение |
|---|---|
| Контрольных точек зафиксировано | 214 |
| Отклонений от допуска выявлено до подписания акта | 31 (14,5 % предъявлений) |
| Отклонений, попавших в эксплуатацию | 0 |
| Отклонено некомплектов фотографий подрядчиков | 23 |

Типовые отклонения пилота: толщина фасадного покрытия ниже проектной, уклон кровли вне допуска, влажность основания выше нормы.

## Ограничения

Восемь домов. Методика не утверждена региональным фондом. Государственного контракта нет.

## Выводы

1. Измерительная приёмка выявляет 14,5 % предъявлений с отклонениями до подписания актов; все отклонения устранены до эксплуатации.
2. Фотоверификация по чек-листам предотвращает оплату неподтверждённых работ (1,2 млн руб. в пилоте).
3. Монте-Карло 3 000 сценариев: предотвращённые потери бюджета капремонта края — медиана 380 млн руб./год. Капзатраты проекта 3,0 млн руб., чистый результат 3,7 млн руб./год, **окупаемость 9,7 месяца (< 2 лет)**. Государственных контрактов на дату подписания нет — проект на поисковой стадии.
