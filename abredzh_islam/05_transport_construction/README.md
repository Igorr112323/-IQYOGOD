# «ТРАНСПОРТНЫЙ КАРКАС»

- **Номинация:** Лучший инновационный проект в сфере транспорта, строительства и ЖКХ
- **Автор:** Абредж Ислам · **Консультант:** Богус Азамат Эдуардович · **Член проектной группы:** Шершнев Игорь Андреевич
- **Суть:** краевой концессионный проект (115-ФЗ) цифровой тарифной интеграции: единая оплата у всех перевозчиков, пересадочный тариф «90 минут», клиринг выручки по фактическим пассажирам, умные остановки как сеть данных о пассажиропотоке. Пилот в Армавире: 18 маршрутов, 92 ТС, 34 остановки; безнал 31 → 78 %, сборы +17 %, поездки +9 %, матрица на 2,4 млн валидаций. Концессия 12 лет, 1,9 млрд руб., капзатраты бюджета — 0.

Файлы: `application.md` — заявка; `images/` — концессия, экономика, контур каркаса; `code/` — пересадка и клиринг; `docs/` — протокол пилота.
