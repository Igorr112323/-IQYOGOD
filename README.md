# Премия IQ года — 2026: 25 инновационных проектов Краснодарского края

Рабочий репозиторий заявок на губернаторский конкурс молодежных инновационных проектов «Премия IQ года». Пять авторов × пять номинаций = 25 уникальных проектов, каждый — со своей темой, стилем подачи и заделом из 6–12 месяцев «предварительной работы».

**Обновление фазы 3 (октябрь 2026 г.):** 17 заявок, получивших при разборе оценку ≤ 22 (аналоги, типовые и заимствованные решения), полностью заменены на новые темы. Каждая новая тема подтверждена **не менее чем 5 публикациями российских СМИ 2025–2026 гг.** (РБК, Коммерсантъ, Кубань 24, Российская газета, Югополис, 93.ру, АиФ-Кубань, МК Кубань, Юг Times, Краснодарские известия и др.) с URL-цитатами в п. 2 заявки. Неизменными остались 8 проектов (отмечены ★).

## Состав каждой заявки

- `application.md` — полная заявка по официальной форме: 13 полей шапки + 11 разделов описания + самооценка по критериям Конкурса (итог 23/23, критерий 8.4 = 3);
- `README.md` — карточка проекта (номинация, автор, суть, цифры задела);
- `images/` — не менее 3 графических файлов: `.mmd` (схема процесса в Mermaid), `.py` (график экономики на matplotlib, строит `.png`, Монте-Карло 3 000 сценариев), `.svg` (чертёж/схема устройства);
- `code/` — фрагменты рабочего кода задела (аналитика, прошивки, модели);
- `docs/протокол_испытаний.md` — протокол испытаний с таблицами данных пилота.
