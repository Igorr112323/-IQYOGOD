# Премия IQ года — 2026: 25 инновационных проектов Краснодарского края

Рабочий репозиторий заявок на губернаторский конкурс молодёжных инновационных проектов «Премия IQ года». Пять авторов × пять номинаций = 25 уникальных проектов. Каждая заявка описывает проект на поисковой стадии (п. 5.1 Положения): задел состоит из кода, расчётов (Монте-Карло, 3 000 сценариев), домашних макетов из радиодеталей, чертежей и схем, выполненных на ПК стендовых проверок. Пилотные внедрения, письма партнёров и контракты в материалах не заявляются — развёртывание описывается как план.

## Все 25 проектов

Андрей Чудиков: «ЭНТОМОЗОНД» (робототехника/ИТ) — шнековый энтомологический зонд с машинным зрением для подсчёта кубышек саранчи и карты очагов; «БИОЩИТ-КУБАНЬ» (АПК/биотех) — биопрепарат на аборигенном штамме *B. subtilis* против корневых гнилей озимой пшеницы; «ИКСОД-НАДЗОР» (здравоохранение) — сеть ловушек иксодовых клещей с морфометрической идентификацией и риск-индексом территорий; «КАРБОКУБАНЬ» (экология/энергетика) — пиролизная переработка лузги подсолнечника в биоуголь; «АКУСТИК-СЕТИ» (транспорт/ЖКХ) — пассивная сейсмоакустика для раннего обнаружения дефектов коллекторов и водоводов.

Максим Климов: «ИСКРА-СТОП» (робототехника/ИТ) — вольтметрическое детектирование источников тока в потоке ТКО с роботизированным извлечением; «МЕДУЗА-АГРО» (АПК/биотех) — береговой комплекс переработки медузы корнерота в биостимулятор «АЗОВ-БИО»; «КЕРАТИН-ГЛИК» (здравоохранение) — неинвазивная рамановская оценка HbA1c по ногтевой пластине; «СОЛАРПАРК» (экология/энергетика) — агровольтаические секции над виноградником: энергия плюс противоградовый щит; «ЭФИР-ДОЖДЬ» (транспорт/ЖКХ) — гиперлокальные карты ливня по затуханию сотовых каналов.

Илья Новиков: «АГРОХОД-2» (робототехника/ИТ) — навесной модуль посекционного распыления для пропашных культур; «ЗЕРНО-РЕНТГЕН» (АПК/биотех) — двухканальный контроль фузариозного зерна на приёмной линии элеватора; «ФИБРА-СТОПА» (здравоохранение) — пассивная стелька на решётках Брэгга для контроля диабетической стопы; «БОРА-5» (экология/энергетика) — ветроэнергетическая установка штормового режима с магнитным подвесом для зоны боры; «ГРУНТ-ЭХО» (транспорт/ЖКХ) — контроль коллекторов методом сейсмической интерферометрии на шумовом поле трафика.

Друг Ильи Новикова: «НОС-КОД» (робототехника/ИТ) — акустические узлы детекции агрессивных собачьих стай на школьных маршрутах; «ЗАМОР-СТОП» (АПК/биотех) — ИК-детекция предзаморного поведения рыбы с опережающей тревогой; «ПОЛЯРИС-БЕРЕГ» (здравоохранение) — поляризационная детекция погружений на необорудованных пляжах; «КАПСУЛА-ЩИТ» (экология/энергетика) — температурно-активируемые огнетушащие капсулы в теле полигона ТКО; «КОЛОДЕЦ-ТРАССА» (транспорт/ЖКХ) — магнитометрическая паспортизация люков с движущегося автомобиля.

Абредж Ислам: «ТРОС-ВЕКС» (робототехника/ИТ) — магнитное дефектоскопное кольцо телеметрии износа лифтовых канатов; «АГРОХОД» / «ЛЕДОЗОР» (АПК/биотех) — наземный микроволновый радиометр мониторинга зимовки озимых и ледяной корки; «РИТМ-КАДРЫ» (здравоохранение) — голосовой скрининг утомления медработников с управленческой связкой в кадровые КПЭ; «СВЕТЛЫЙ РАЙОН» (экология/энергетика) — платформенная модель ЭСКО-модернизации освещения сельских поселений; «ГАЗ-ДОЗОР» (транспорт/ЖКХ) — домовая лазерная система контроля утечек газа на выходе вентшахты МКД.

## Структура папки заявки

- `ЗАЯВКА.md` — единый файл заявки (шапка, данные автора, разделы 1–11, самооценка, подписи, приложения).
