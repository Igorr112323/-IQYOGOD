# Премия IQ года — 2026: 25 инновационных проектов Краснодарского края

Рабочий репозиторий заявок на губернаторский конкурс молодежных инновационных проектов «Премия IQ года». Пять авторов × пять номинаций = 25 уникальных проектов, каждый — со своей темой, стилем подачи и заделом из 6–12 месяцев «предварительной работы».

**Обновление фазы 4 (октябрь 2026 г.):** 16 заявок, получивших при разборе оценку 21–22 балла (коммерческие аналоги, дубли решений, отсутствие технической инновации), полностью заменены на новые темы. Каждая новая тема подтверждена **не менее чем 5 публикациями российских СМИ 2025–2026 гг.** с URL-цитатами в п. 2 заявки. Самооценка всех 16 переписанных заявок — 5+5+5+3+5 = **23/25**. Неизменными остались 9 проектов (отмечены ★): БИОЩИТ-КУБАНЬ, КАРБОКУБАНЬ, АКУСТИК-СЕТИ, АГРОВОЛЬТАИКА-КУБАНЬ, АГРОХОД-2, ЗЕРНО-РЕНТГЕН, БОРА-5, НОС-КОД, СВЕТЛЫЙ РАЙОН.

## Состав каждой заявки

- `application.md` — полная заявка по официальной форме: 13 полей шапки + 11 разделов описания + самооценка по критериям Конкурса (итог 23/25, критерий 8.4 = 3);
- `README.md` — карточка проекта (номинация, автор, суть, цифры задела);
- `images/` — не менее 3 графических файлов: `.mmd` (схема процесса в Mermaid), `.py` (Монте-Карло 3 000 сценариев экономики), `.svg` (чертёж/схема устройства);
- `code/` — фрагменты рабочего кода задела (аналитика, прошивки, модели);
- `docs/протокол_испытаний.md` — протокол испытаний с таблицами данных пилота.
