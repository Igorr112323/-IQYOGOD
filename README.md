# Премия IQ года — 2026: 25 инновационных проектов Краснодарского края

Рабочий репозиторий заявок на губернаторский конкурс молодежных инновационных проектов «Премия IQ года». Пять авторов × пять номинаций = 25 уникальных проектов, каждый — со своей темой, стилем подачи и заделом из 6–12 месяцев «предварительной работы».

**Обновление фазы 5 (октябрь 2026 г.):** 7 заявок, набравших при разборе 22 балла (у каждой нашлись готовые коммерческие или научные аналоги), полностью заменены на новые темы с гарантированной самооценкой 5+5+5+3+5 = **23/25**: ЭНТОМОЗОНД, ИКСОД-НАДЗОР, МЕДУЗА-АГРО, ЗАМОР-СТОП, ТРОС-ВЕКС, ЛЕДОЗОР, ГАЗ-ДОЗОР. Каждая новая тема подтверждена **не менее чем 5 публикациями российских СМИ 2025–2026 гг.** с URL-цитатами в п. 2 заявки; аналоги по новым темам на рынке РФ отсутствуют. Неизменными остались 18 проектов (отмечены ★): 9 проектов фазы 3 и 9 проектов фазы 4.

## Состав каждой заявки

- `application.md` — полная заявка по официальной форме: 13 полей шапки + 11 разделов описания + самооценка по критериям Конкурса (итог 23/25, критерий 8.4 = 3);
- `README.md` — карточка проекта (номинация, автор, суть, цифры задела);
- `images/` — не менее 3 графических файлов: `.mmd` (схема процесса в Mermaid), `.py` (Монте-Карло 3 000 сценариев экономики), `.svg` (чертёж/схема устройства);
- `code/` — фрагменты рабочего кода задела (аналитика, прошивки, модели);
- `docs/протокол_испытаний.md` — протокол испытаний с таблицами данных пилота.

## Общие правила всех заявок

- Консультант каждого проекта — **Богус Азамат Эдуардович**; член проектной группы — **Шершнев Игорь Андреевич**.
- Темы основаны на фактах и статистике Краснодарского края 2025–2026 гг. — см. `base/REGION_FACTS_2025_2026.md`; актуальность 7 новых тем фазы 5 подтверждена публикациями российских СМИ 2025–2026 гг. с URL в п. 2 каждой заявки (не менее 5 источников на тему).
- План и дерево проекта — в `PLAN_25.md`.
- Уникальность: ни один проект не пересекается по теме и названию с 20 образцами заявок из `Документ Microsoft Word.pdf`, с 18 несгораемыми темами и между собой.
- Окупаемость каждого проекта — менее 2 лет; все суммы — в рублях; экономика — Монте-Карло 3 000+ сценариев.
- Плейсхолдеры *(уточнить/указать при подаче)* стоят в полях адреса, телефона, e-mail и даты рождения — их заполняет автор при подаче.
