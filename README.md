## Состав каждой заявки

- `application.md` — полная заявка по официальной форме: 13 полей шапки + 11 разделов описания + самооценка по критериям Конкурса;
- `README.md` — карточка проекта (номинация, автор, суть, цифры задела);
- `images/` — не менее 3 графических файлов: `.mmd` (схема процесса в Mermaid), `.py` (график экономики на matplotlib, строит `.png`), `.svg` (чертёж/схема устройства);
- `code/` — фрагменты рабочего кода задела (аналитика, прошивки, 3D-модели в `.scad`);
- `docs/протокол_испытаний.md` — протокол испытаний с таблицами реальных данных пилота.
