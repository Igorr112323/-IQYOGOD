# ДОПЛЕР-СТАДО

**Номинация:** робототехника, ИТ и телекоммуникации. **Автор:** Чудиков Андрей. **Консультант:** Богус Азамат Эдуардович. **Член группы:** Шершнев Игорь Андреевич.

Бесконтактная система мониторинга локомоции и жвачки молочного скота на основе микродоплеровских сигнатур радиолокационного сигнала (24 ГГц). Без меток, без камер, без участия персонала: арочный модуль на выходе из доильного зала видит каждую корову дважды в сутки и предупреждает зоотехника о субклинической хромоте за 2–9 суток до клинического диагноза.

## Проблема

Кадровый дефицит животноводства Кубани (7,9 тыс. позиций в сельском хозяйстве, 11,2 тыс. работников не хватает АПК края — Эксперт Юг, Кубань Информ, 2025–2026) исключает регулярный индивидуальный осмотр стада. Хромота поражает 20–40 % коров; субклиническая фаза — до недель потери 1,5–3 кг молока в сутки без видимых признаков.

## Уникальное решение

Классификация состояния животного по микродоплеровской сигнатуре прохода — периодические спектральные компоненты шага и микровибраций жвачки. Коммерческих аналогов безметочного радиолокационного мониторинга КРС не выявлено.

## Задел

- прототип на ферме-партнёре (420 коров, Динской район), 8 недель эксплуатации;
- датасет 14 800 проходов 42 коров с ветеринарной разметкой;
- чувствительность к субклинической хромоте 0,89, специфичность 0,83; опережение клиники — медиана 4 суток;
- признак жвачки верифицирован видеофиксацией (совпадение 0,93);
- Монте-Карло 3 000: эффект 1,31 млн руб./год на 600 голов, окупаемость 11,3 месяца.
