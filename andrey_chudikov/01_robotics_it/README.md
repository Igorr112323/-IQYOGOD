# «АГРОСПЕКТР-К»

- **Номинация:** Лучший инновационный проект в сфере робототехники, компьютерных технологий и телекоммуникаций
- **Автор:** Чудиков Андрей · **Консультант:** Богус Азамат Эдуардович · **Член проектной группы:** Шершнев Игорь Андреевич
- **Суть:** наземный мультиспектральный комплекс (4 канала 550/680/760/850 нм, разрешение 1,8 мм/пикс) с нейросетевой классификацией (0,913) обнаруживает очаги болезней озимой пшеницы на 9 суток раньше агронома и выдаёт карты для адресной обработки. Себестоимость макета 340 тыс. руб. — в 8 раз ниже бортовых аналогов; эффект хозяйства ≈ 2,87 млн руб./сезон на 500 га.

Файлы: `application.md` — заявка; `images/` — схема, график, чертёж; `code/` — расчётный код и 3D-модель; `docs/` — протокол испытаний.
