# «КАРДИОКЛИМАТ-КУБАНЬ»

- **Номинация:** Лучший инновационный проект в сфере здравоохранения, биомедицины, фармацевтики
- **Автор:** Чудиков Андрей · **Консультант:** Богус Азамат Эдуардович · **Член проектной группы:** Шершнев Игорь Андреевич
- **Суть:** система поддержки принятия решений, прогнозирующая всплески сердечно-сосудистых обращений за 24–72 ч в периоды жары на основе сопряжения метеорядов и агрегированных медицинских сводок. Введён «индекс жаровой кардионагрузки» (ЖКИ). Модель: ROC-AUC 0,81 на отложенном сезоне 2025 г.; датасет 5 479 записей; Монте-Карло (3 000 сценариев) — медиана предотвращённых расходов ОМС 38 млн руб./сезон по 5 пилотным муниципалитетам. Капзатраты развёртывания 2,4 млн руб.; плательщик — краевой минздрав; окупаемость < 1 сезона; масштабирование на 44 МО.

Файлы: `application.md` — заявка; `images/` — конвейер, экономика, схема дашборда; `code/` — признаки и модель; `docs/` — протокол валидации.
