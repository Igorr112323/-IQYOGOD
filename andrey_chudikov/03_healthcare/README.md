# «КАРДИОКЛИМАТ-КУБАНЬ»

- **Номинация:** Лучший инновационный проект в сфере здравоохранения, биомедицины, фармацевтики
- **Автор:** Чудиков Андрей · **Консультант:** Богус Азамат Эдуардович · **Член проектной группы:** Шершнев Игорь Андреевич
- **Суть:** система поддержки принятия решений, прогнозирующая всплески сердечно-сосудистых обращений за 24–72 ч в периоды жары на основе сопряжения метеорядов и агрегированных медицинских сводок. Введён «индекс жаровой кардионагрузки» (ЖКИ). Модель: ROC-AUC 0,81 на отложенном сезоне 2025 г.; датасет 5 479 записей; расчётный эффект — 31–47 млн руб. предотвращённых расходов ОМС за сезон по 5 пилотным муниципалитетам.

Файлы: `application.md` — заявка; `images/` — конвейер, экономика, схема дашборда; `code/` — признаки и модель; `docs/` — протокол валидации.
