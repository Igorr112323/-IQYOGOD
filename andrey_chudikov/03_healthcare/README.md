# ЗРАЧОК-ВЕКС

**Номинация:** здравоохранение, биомедицина и фармация. **Автор:** Чудиков Андрей. **Консультант:** Богус Азамат Эдуардович. **Член группы:** Шершнев Игорь Андреевич.

Автоматизированный скрининг когнитивного снижения у пожилых по видеопупиллометрии на смартфоне с ИК-подсветкой: 90 секунд на человека, результат — категория риска и маршрут к неврологу. Решение для диспансеризации в условиях, когда неврологов на всех не хватает.

## Проблема

УКР встречается у 10–36,7 % людей 60+, в РФ 1,248 млн пациентов с деменцией (ReClin, 2026); симптомы могут наблюдаться у 10 млн россиян (АБН24/НАФИ, 2026). На Кубани дефицит 5,4 тыс. медработников, 1,1 резюме на вакансию врача (РБК, Юга.ру, 2025) — ранняя диагностика упирается в недоступность специалиста.

## Уникальное решение

Параметры фотомоторной реакции зрачка (латентность, скорость сужения и восстановления) связаны с когнитивным статусом. Клинических средств массового скрининга на этой основе в РФ не применяется; наша насадка-упор с ИК-подсветкой и возраст-нормированная модель делают измерение доступным медсестре.

## Задел

- насадка-прототип (ИК 850 нм, калиброванный стимул), совместима с 3 смартфонами;
- датасет 214 участников, 2 354 записи, референс по MoCA;
- AUC 0,86 (норма/УКР), 0,89 (норма/деменция); чувствительность 0,84, специфичность 0,78;
- Монте-Карло 3 000: прибыль медиана 8,9 млн руб./год, окупаемость 5,4 месяца.
