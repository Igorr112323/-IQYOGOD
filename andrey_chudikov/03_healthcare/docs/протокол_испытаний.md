# Протокол пилотного исследования системы «ЗРАЧОК-ВЕКС»

**Период:** 03.02.2026 — 25.09.2026.
**Место:** кабинеты медицинской профилактики ГБУЗ «Городская поликлиника № 3» и № 12, г. Краснодар; референсная оценка — отделение неврологии ККБ № 1.
**Оборудование:** насадка-упор с ИК-подсветкой 850 нм, прототип 3 шт.; смартфоны 3 моделей (камера ≥ 12 Мп, 60 к/с).
**Ответственные:** автор проекта (методика, клиническое взаимодействие), Шершнев И.А. (компьютерное зрение), врач-невролог (референсная разметка).

## 1. Дизайн

1. Участники — посетители кабинетов профилактики 60–84 лет, добровольное информированное согласие; когнитивный статус оценён по MoCA (референс: норма ≥ 26).
2. Измерение: 90 секунд на человека; три световых стимула по 0,4 с с интервалом 4 с; регистрация фронтальной камерой через насадку.
3. Скрининг ослеплён к результату MoCA; разметка статуса выполнялась независимо.

## 4. Монте-Карло (экономика)

3 000 сценариев подписной модели (`images/zrachok_economics.py`): портфель медиана 62 учреждения, выручка медиана 34,2 млн руб./год, прибыль медиана 8,9 млн руб./год, окупаемость стартовых затрат 1,6 млн руб. — медиана 5,4 месяца, 95-й процентиль 10,1 месяца, доля сценариев с окупаемостью до 24 месяцев 0,99.

## 5. Ограничения

- пилот выполнен в двух поликлиниках одного города; многоцентровая валидация — следующий этап;
- система является скрининговым инструментом поддержки маршрутизации, диагнозы не ставит;
- регистрационное удостоверение медицинского изделия не оформлялось;
- на 3,1 % записей сегментация зрачка оказалась нечитаемой (блики, катаракта) — такие записи направляются на повторное измерение.

## 6. Заключение

Способ видеопупиллометрии на смартфоне продемонстрировал приемлемую для скрининга точность и устойчивость при выполнении медсестрой без специальной подготовки. Система рекомендуется к многоцентровой валидации и подготовке досье медицинского изделия.
