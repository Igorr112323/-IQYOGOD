# Протокол валидации системы «ФОНО-ВЕКС»

- **Дата:** 01.06.2026 – 31.08.2026
- **Место:** ЦРБ Динского и Кореновского районов Краснодарского края (прикреплённые контингенты 65+)
- **Объект:** действующий прототип телефонного голосового скрининга: автоматический обзвон, запись диалога, извлечение просодических признаков, триажная классификация
- **Исполнители:** Чудиков А. (методика, работа с ЦРБ), Шершнев И.А. (платформа, модели); научное руководство — Богус А.Э.; эталонные оценки — врачи и психологи ЦРБ

## Объём данных

| Показатель | Значение |
|---|---|
| Участников (65–89 лет) | 412 |
| Записей диалогов | 1 236 (по 3 на участника) |
| Выполнено автоматических звонков за опытную эксплуатацию | 11 340 |
| Доля успешных диалогов | 71 % |
| Эталон | шкала GDS-15 в пределах ± 5 дней от звонка |

## Результаты валидации (независимая выборка, 20 %, стратификация по возрасту и полу)

| Метрика | Значение |
|---|---|
| Чувствительность (GDS-15 ≥ 11) | 0,86 |
| Специфичность | 0,79 |
| Согласованность триажной категории с решением врача | 83 % |
| Доля звонков с достаточным качеством записи (SNR) | 94 % |

## Наблюдения

Просодические маркеры (снижение вариативности основного тона, удлинение пауз, падение энергии голоса) устойчиво ассоциированы с повышенным баллом GDS-15; на записях с выраженной диалектной окраской качество распознавания снижалось не более чем на 4 п.п. после калибровки. Участники характеризовали звонки как «понятные и ненавязчивые» (анкета после 3-го звонка, 156 ответов).

## Ограничения

Два района; клинико-экономические оценки расчётные; система не является зарегистрированным медицинским изделием.

## Выводы

1. Телефонный голосовой скрининг без смартфона состоятелен для целевой группы 65+: чувствительность 0,86 при специфичности 0,79 против эталона GDS-15.
2. Канал обычного телефонного звонка обеспечивает охват группы, недоступной мобильным приложениям (доля успешных диалогов 71 %).
3. Монте-Карло (3 000 итераций): эффект здравоохранения района медиана 3,1 млн руб./год; капзатраты проекта 1,8 млн руб., чистый результат 3,6 млн руб./год при 12 районах, **окупаемость 6 месяцев (< 2 лет)**. Платных договоров на дату подписания нет — проект на поисковой стадии.
