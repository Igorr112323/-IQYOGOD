# «БИОЩИТ-КУБАНЬ»

- **Номинация:** Лучший инновационный проект в сфере АПК, биотехнологий и пищевой промышленности
- **Автор:** Чудиков Андрей · **Консультант:** Богус Азамат Эдуардович · **Член проектной группы:** Шершнев Игорь Андреевич
- **Суть:** биопрепарат на аборигенном штамме *B. subtilis* БК-12 против корневых гнилей озимой пшеницы. Антагонизм к *F. graminearum* 17,3 мм; биологическая эффективность в сосудистом опыте 37,8 %; сухая формуляция на рисовой шелухе (жизнеспособность 92 % за 90 сут); себестоимость 85 руб./га против 550 руб./га у химического эталона. Монте-Карло 3 000 сезонов: экономия 465 тыс. руб./сезон на 1 000 га. Капзатраты линии 980 тыс. руб., окупаемость 1,2–1,5 сезона (< 2 лет). Рынок края — свыше 1,6 млн га озимой пшеницы.

Файлы: `application.md` — заявка; `images/` — схема, экономика, чертёж ферментера; `code/` — анализ роста и импедансный контроль; `docs/` — протокол сосудистого опыта.
